    Function `upgrade_v0_to_v1(data: dict[str, Any]) -> dict[str, Any]`:
    - Deep-copy input data to avoid mutation
    - Set `$schema` to "ocsd-routine-v1"
    - Add missing top-level fields with defaults:
      - `version`: "1.0.0"

      - `theme`: None
      - `updated_at`: data.get("created_at", datetime.now(timezone.utc).isoformat())
    - For each step in `data["steps"]`:
      - Get `node_id` from step (v0 already has node_id)
      - Replace `snippet_path`: `f"snippets/{node_id}.png"` (was `snippets/step_NN.png`)
      - Replace `embedding_path`: `f"embeddings/{node_id}.npy"` (was `embeddings/step_NN.npy`)

        - `ocr_text`: step.get("ocr_text") or None
        - `position_pct`: {"x_pct": center x from bbox_pct, "y_pct": center y from bbox_pct}
        - `region_hint`: step.get("region_hint", "center")
      - Ensure `confidence` field exists (default 0.0)
    - Compute and set checksum via `calculate_routine_checksum(data["steps"], data.get("graph", {}))`
    - Set `signature`: None
    - Reorder keys to match v1 logical order (build new dict with keys in order)
    - Return the upgraded dict
    - Log: `logger.info("Upgraded routine '%s' from v0 to v1 (in-memory)", data.get("name", "unknown"))`
