    Method `to_dict(self) -> dict[str, Any]`:
    - Build dict in exact key order: `$schema` ("ocsd-routine-v1"), `name`, `version`, `description`, `author`, `author_display`, `created_at`, `updated_at`, `category`, `tags`, `programs`, `platform`, `theme`, `start_from`, `resolution`, `steps`, `graph` (from `self.graph.to_dict()`), `checksum` (from `calculate_routine_checksum`), `signature` (None)
    - Python 3.7+ dicts preserve insertion order, so no OrderedDict needed

    Class method `from_dict(cls, data: dict[str, Any]) -> Routine`:
    - Extract all fields from dict
    - Build OCSDGraph via `OCSDGraph.from_dict(data.get("graph", {}))` — if graph key missing, use empty OCSDGraph
    - Verify checksum on load: compute expected from steps+graph, compare to stored. If mismatch, raise `ValueError("Routine integrity check failed: checksum mismatch")`

    Method `save(self, directory: Path) -> None`:
    - `directory.mkdir(parents=True, exist_ok=True)`
    - `(directory / "snippets").mkdir(exist_ok=True)`
    - `(directory / "embeddings").mkdir(exist_ok=True)`
    - Build ordered dict via `to_dict()`
    - Write to `directory / "routine.json"` with `json.dump(..., indent=2, ensure_ascii=False, default=_json_default)`
    - Log: `logger.info("Saved routine '%s' v%s to %s", self.name, self.version, directory)`

    Class method `load(cls, directory: Path) -> Routine`:
    - Read `directory / "routine.json"`
    - `json.load()` then `cls.from_dict(data)`

    - Return step dict with keys: step_index, node_id, element_type, label, caption, confidence, action, bbox, bbox_pct, region_hint, anchors, snippet_path (f"snippets/{node_id}.png"), embedding_path (f"embeddings/{node_id}.npy"), dry_run_passed (True)
    - Always use forward slashes in paths (string concatenation with `/`, never Path objects for JSON paths)
