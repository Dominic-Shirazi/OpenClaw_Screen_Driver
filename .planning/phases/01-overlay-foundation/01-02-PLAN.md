    **`recorder/overlay/controller.py`**:
    - `from __future__ import annotations`
    - `import logging`, `import sys`
    - `from typing import Any, Callable`
    - `from recorder.overlay.state import OverlayState, transition`
    - `logger = logging.getLogger(__name__)`
    - `class OverlayController:` with Google-style class docstring explaining it's the public API for the overlay.

    Public API:
    - `__init__(self, *, on_selection: Callable[[int, int, int, int], None] | None = None, on_state_changed: Callable[[OverlayState], None] | None = None, on_save: Callable[[], None] | None = None, on_abort: Callable[[], None] | None = None)`:
      - Store callbacks
      - self._state = OverlayState.READY
      - self._view: OverlayView | None = None (lazy import to avoid circular)
      - self._hotkey_listener: Any = None
      - self._is_active = False

    - `@property def state(self) -> OverlayState:` — returns self._state

    - `@property def is_active(self) -> bool:` — returns self._is_active

    - `def show(self) -> None:` — creates OverlayView (lazy import from recorder.overlay.view), sets geometry to primary screen, calls view.show(), view.raise_(), applies initial state, starts hotkey listener via _create_hotkey_listener(on_toggle=self._handle_toggle, on_close=self._handle_close). Sets self._is_active = True.

    - `def close(self) -> None:` — stops hotkey listener, closes and nulls view, sets _is_active = False, resets state to READY.

    - `def hide_for_capture(self) -> None:` — delegates to view.hide_for_capture() if view exists

    - `def show_after_capture(self) -> None:` — delegates to view.show_after_capture() if view exists

    - `def set_bboxes(self, bboxes: list[dict[str, Any]]) -> None:` — delegates to view.render_bboxes() if view exists

    - `def clear_bboxes(self) -> None:` — delegates to view.clear_bboxes() if view exists

    Private methods:
    - `def _handle_toggle(self) -> None:` — calls transition(self._state, "f2"). If new state is not None, updates self._state, calls view.apply_state(new_state), fires on_state_changed callback. Log state change.

    - `def _handle_close(self) -> None:` — if state is RECORDING, treat as save (call on_save callback). If state is READY/PAUSED, treat as abort (call on_abort callback). Then call self.close().

    - `def _fire_callback(self, cb: Callable[..., Any] | None, *args: Any) -> None:` — helper that calls callback in try/except, logs errors.
