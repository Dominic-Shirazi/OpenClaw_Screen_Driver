       - `def ensure_xcb_platform() -> None`: If `sys.platform == "win32"`, return immediately. Check `XDG_SESSION_TYPE == "wayland"` or `WAYLAND_DISPLAY` is set. If either, set `os.environ["QT_QPA_PLATFORM"] = "xcb"` and log info. MUST be called before QApplication creation.
       - `def set_click_through_linux(widget: Any, passthrough: bool) -> None`: calls `widget.setAttribute(Qt.WidgetAttribute.WA_TransparentForMouseEvents, passthrough)`. Import Qt inside function to avoid top-level PyQt6 import when not needed.

    3. Create `recorder/overlay/capture_guard.py` with:
       - `from __future__ import annotations`
       - `import logging`, `import sys`, `import time`
       - `from contextlib import contextmanager`

       - `from PyQt6.QtWidgets import QApplication`
       - `from core.config import get_config`
       - `logger = logging.getLogger(__name__)`
       - `@contextmanager` `def capture_guard(view: Any, flush_ms: int | None = None) -> Generator[None, None, None]`:

         - Call `view.hide()`
         - Call `QApplication.processEvents()`
         - If `sys.platform == "win32"`: call `from recorder.overlay.platform_win32 import dwm_flush; dwm_flush()`

         - `yield` inside try/finally
         - In finally: `view.show()`, `QApplication.processEvents()`
