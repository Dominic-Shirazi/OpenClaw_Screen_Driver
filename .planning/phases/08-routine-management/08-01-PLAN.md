    1. Create `routine/version.py` with two functions:
       - `def bump_minor(version: str) -> str:` -- splits on ".", increments parts[1], resets parts[2] to 0
       - `def bump_patch(version: str) -> str:` -- splits on ".", increments parts[2]
       Both use `from __future__ import annotations`, type hints, Google docstrings.

    2. Create `routine/management.py` with three functions:

       `def fork_routine(source_dir: Path, new_name: str, truncate_at: int | None = None, base_dir: Path | None = None) -> Path:`
       - Compute target_dir as `(base_dir or get_routine_dir()) / new_name`
       - Raise ValueError if target_dir exists
       - `shutil.copytree(source_dir, target_dir)`
       - Load routine from target_dir via `Routine.load(target_dir)`
       - Set `routine.name = new_name`, `routine.version = "1.0.0"`, update `updated_at`
       - If truncate_at is not None: truncate `routine.steps = routine.steps[:truncate_at]`, rebuild graph from remaining steps (create new OCSDGraph, add nodes for each remaining step's node_id), remove orphaned snippet/embedding files from target_dir by scanning snippets/ and embeddings/ and deleting files whose node_id is not in the remaining steps
       - `routine.save(target_dir)` and return target_dir

       `def delete_routine(routine_dir: Path, skip_confirm: bool = False) -> bool:`
       - Load routine name via `Routine.load(routine_dir)` for display
       - Unless skip_confirm: use `from rich.prompt import Confirm` to ask `'Delete routine "{name}" and all its files? This cannot be undone.'`
       - If confirmed (or skip_confirm=True): `shutil.rmtree(routine_dir)`, log, return True
       - If declined: return False

       `def inspect_routine(routine_dir: Path, as_json: bool = False) -> None:`
       - Load routine via `Routine.load(routine_dir)`
       - If as_json: `import json; print(json.dumps(routine.to_dict(), indent=2))`; return
       - Otherwise use Rich Console and Table:
         - Header: `[bold]{routine.name}[/bold] v{routine.version}`, step count, platform, programs, created_at
         - Table columns: "#" (width=4), "Action" (width=14), "Label" (width=30), "Bbox" (width=20), "Snippet" (width=4, justify="center")
         - For each step: extract step_index, action, label (truncated to 30 chars), bbox as "(x,y) wxh", check if snippet file exists (green checkmark or red dash)

    3. Create `tests/test_routine_management.py` with tests written FIRST (RED phase):
       - Use `tmp_path` fixture to create a temporary routine directory with a minimal valid routine
       - Helper `_make_test_routine(tmp_path, name, num_steps)` that creates a routine dir with Routine.save() and dummy snippet/embedding files
       - Test functions for all behaviors listed above
       - Mock `rich.prompt.Confirm.ask` for delete tests using `monkeypatch` or `unittest.mock.patch`
       - For inspect tests, capture stdout using `capsys` fixture

    All files must use `from __future__ import annotations`, type hints on all signatures, `logging.getLogger(__name__)`, Google-style docstrings.
