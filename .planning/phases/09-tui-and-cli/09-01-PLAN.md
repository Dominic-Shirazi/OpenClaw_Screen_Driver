    - `resolve_routine_path(name_or_path: str) -> Path`: Check if argument is an existing file/directory path first (`Path(name_or_path).exists()`). If it's a file, return its parent.     - `output_routines(routines: list[RoutineInfo], as_json: bool) -> None`: If `as_json`, print `json.dumps` of list of dicts with name/path/version. Otherwise, Rich Table with columns: Name (bold), Version (dim), Path (dim).
    - `parse_params(param_list: list[str]) -> dict[str, str]`: Parse list of "key=value" strings into a dict. Raise `typer.BadParameter` if any entry lacks `=`.

    Create `cli/app.py`:
    - `app = typer.Typer(name="ocsd", help="OpenClaw Screen Driver -- AI-powered screen automation", no_args_is_help=False, rich_markup_mode="rich", pretty_exceptions_enable=False)`
    - `@app.callback(invoke_without_command=True)` `main_callback(ctx: typer.Context)`: If `ctx.invoked_subcommand is None`, lazy-import `from cli.tui import run_tui` and call `run_tui()`.
    - `@app.command()` `record(name: str = typer.Argument(..., help="Routine name"))`: Lazy-import and call `show_loading_screen()` from `cli.tui`, then lazy-import `cmd_record` from `recorder.record_flow` and call `cmd_record(name)`. Wrap in try/except, call `show_error` on failure.
    - `@app.command("run")` `run_command(name: str, speed: float = typer.Option(1.0, "--speed"), json_output: bool = typer.Option(False, "--json"), param: list[str] = typer.Option([], "--param"))`: Resolve routine path via `resolve_routine_path(name)`. Parse params via `parse_params(param)`. Lazy-import `show_loading_screen` from `cli.tui` and call it. Lazy-import `run_routine` from `routine.runner` and call with `routine_dir=path`. If `json_output`, print result as JSON. Otherwise, print Rich summary panel.
    - `@app.command("list")` `list_command(json_output: bool = typer.Option(False, "--json"))`: Call `list_routines()` and `output_routines(routines, json_output)`.
    - `@app.command()` `inspect(name: str, json_output: bool = typer.Option(False, "--json"))`: Resolve path, call `inspect_routine(path, as_json=json_output)`.
    - `@app.command()` `update(name: str)`: Resolve path, lazy-import `show_loading_screen` and call it, lazy-import `UpdateSession` and `Routine`, load routine and create session. Print Rich panel summary after.
    - `@app.command()` `fork(name: str, new_name: str)`: Resolve path, call `fork_routine(source_dir=path, new_name=new_name)`. Print success with Rich.
    - `@app.command()` `delete(name: str, yes: bool = typer.Option(False, "--yes"))`: Resolve path, call `delete_routine(path, skip_confirm=yes)`.
    - Create `hub` sub-app: `hub_app = typer.Typer(name="hub", help="Routine Hub (V2)")`. Add `@hub_app.command()` `search(query: str)`: Print "Hub coming soon in V2. For now, routines are stored locally in ~/.ocsd/routines/".
    - Register: `app.add_typer(hub_app)`
    - `def main() -> None: app()`

    Update `pyproject.toml`:
    - Add `"typer>=0.12"` and `"rich>=13.0"` to core `dependencies` list (move rich from optional tui group to core).
