  <action>
    Create `cli/_keys.py` with a single function:
    - `read_key() -> str`: Cross-platform single keypress reader.
      - On Windows (`sys.platform == "win32"`): Use `msvcrt.getwch()`. Handle special key prefix (`\x00` or `\xe0`) followed by second char: `H` -> "up", `P` -> "down", `K` -> "left", `M` -> "right". `\r` -> "enter", `\x1b` -> "escape", `\x08` -> "backspace". Return printable characters as-is.
      - On Unix: Use `tty.setraw(fd)` + `termios.tcgetattr` / `tcsetattr` to read raw input. Handle escape sequences: `\x1b[A` -> "up", `\x1b[B` -> "down". `\r` -> "enter", `\x1b` alone -> "escape", `\x7f` -> "backspace". Return printable chars as-is. Always restore terminal settings in `finally` block.

    Create `cli/tui.py` with these functions:

    **`_load_features() -> list[dict[str, str]]`**: Load features from `cli/features.yml` using `yaml.safe_load`. Use `Path(__file__).parent / "features.yml"` for the path. Return list of dicts with `text` and `status` keys. If file missing, return a hardcoded fallback list with 3 items.

    **`show_loading_screen() -> None`**: Synchronous Rich Live display.
    - Create `rich.progress.Progress` with `SpinnerColumn`, `TextColumn("[bold]{task.description}")`, `BarColumn()`, `TextColumn("{task.completed}/{task.total}")`.
    - Add 3 tasks: "OmniParser model" (total=1), "CLIP embeddings" (total=1), "VLM connectivity" (total=1).
    - Show the progress inside a `rich.live.Live` context with `refresh_per_second=10`.
    - For each model, attempt to load/check and mark completed:
      - OmniParser: Try `from detection.omniparser import get_omniparser; get_omniparser()`. Catch ImportError, log as "OmniParser not installed".
      - CLIP: Try `from detection.clip_embedder import CLIPEmbedder; CLIPEmbedder()`. Catch ImportError.
      - VLM: Try a quick connectivity check (import `core.config.get_config`, check if vlm config exists). This is fast.
    - After models, show feature ticker: load features, print 3-4 shipped features with green checkmark prefix and 1-2 coming_soon with dim "coming soon" suffix. Use `Console.print` (outside Live context).
    - Print a blank line after ticker to cleanly separate from menu.

    **`_show_menu(include_routine_actions: bool = True) -> tuple[str, dict]`**: Arrow-key navigable menu.
    - Define menu items as list of tuples: `(label, command, enabled)`.
      - ("Record Routine", "record", True)
      - ("Run Routine", "run", True)
      - ("Update Routine", "update", True)
      - ("Fork Routine", "fork", True)
      - ("List Routines", "list", True)
      - ("Inspect Routine", "inspect", True)
      - ("Hub Browse", "hub", False)  # V2+ greyed out
      - ("Voice Record", "voice", False)  # V2+ greyed out
      - ("Quit", "quit", True)
    - Track `selected_index` starting at 0. Render menu using `rich.live.Live`:
      - For each item, if selected: `[bold cyan]> {label}[/]`. If not selected and enabled: `  {label}`. If not enabled: `  [dim]{label} [italic]Feature inbound[/italic][/dim]`.
    - Read keys in a loop via `read_key()`:
      - "up": decrement index, skip disabled items, wrap around.
      - "down": increment index, skip disabled items, wrap around.
      - "enter": if current item is enabled, break and return `(command, {})`.
      - "escape" or "q": return `("quit", {})`.
    - After menu selection, if command is "run", "update", "fork", or "inspect": show searchable routine list via `_show_routine_browser()` and return `(command, {"routine_path": selected_path})`.
    - If command is "record": prompt for routine name using `rich.prompt.Prompt.ask("Routine name")` and return `("record", {"routine_name": name})`.
    - If command is "fork": prompt for source name, then new name.

    **`_show_routine_browser() -> Path | None`**: Searchable routine list.
    - Call `list_routines()` to get all routines.
    - If empty, print "No routines found" message and return None.
    - Track `filter_text` (string) and `selected_index` (int).
    - In a `rich.live.Live` loop:
      - Filter routines where `filter_text.lower()` is in `routine.name.lower()`.
      - Render a Rich Table showing filtered routines with `#`, Name, Version columns. Highlight the selected row with `[bold cyan]`.
      - Show filter prompt: `"Type to filter: {filter_text}_"`.
      - Read keys: printable chars append to `filter_text` and reset `selected_index` to 0. "backspace" removes last char. "up"/"down" navigate. "enter" returns selected routine's path. "escape" returns None.
    - Return the selected `RoutineInfo.path` or None.

    **`run_tui() -> None`**: Main TUI entry point.
    - Call `show_loading_screen()`.
    - Call `_show_menu()` to get `(command, kwargs)`.
    - If command == "quit": return.
    - If command == "record": lazy-import `from cli._minimize import minimize_terminal, restore_terminal`. Call `minimize_terminal()`. Lazy-import `from recorder.record_flow import cmd_record`. Call `cmd_record(kwargs.get("routine_name"))`. Call `restore_terminal()`. Print completion summary.
    - If command == "run": Similar pattern with `run_routine`.
    - If command == "update": Similar with UpdateSession.
    - If command == "fork": Call `fork_routine`.
    - If command == "list": Call `list_routines()` and `output_routines()`.
    - If command == "inspect": Call `inspect_routine`.
    - After action completes, loop back to `_show_menu()` unless user chose quit.

    All functions must have type hints, Google-style docstrings, `from __future__ import annotations`, and use `logging.getLogger(__name__)`.
