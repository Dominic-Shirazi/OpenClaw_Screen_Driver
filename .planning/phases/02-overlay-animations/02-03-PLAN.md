**Raindrop dataclass (module-level):**
```python
class _Raindrop:
    """Expanding/fading ripple circle within the donut cloud."""
    __slots__ = ("center", "max_radius", "progress", "speed")

    def __init__(self, center: QPointF, max_radius: float) -> None:
        self.center = center
        self.max_radius = max_radius
        self.progress: float = 0.0
        self.speed: float = 0.3 + random.random() * 0.4

    def tick(self, dt: float) -> bool:
        """Advance ripple. Returns False when complete."""
        self.progress += self.speed * dt
        return self.progress < 1.0

    @property
    def radius(self) -> float:
        return self.max_radius * self.progress

    @property
    def opacity(self) -> float:
        return max(0.0, 1.0 - self.progress)
```

**DonutCloudLayer class (QGraphicsObject):**
- `__init__(self, center_x: float, center_y: float, radius_x: float = 60.0, radius_y: float = 60.0) -> None`:
  - `super().__init__()`
  - Store `_center = QPointF(center_x, center_y)`
  - `_radius_x: float = radius_x`
  - `_radius_y: float = radius_y`
  - `_color = QColor(255, 50, 50)` (red = editing)
  - `_target_color = QColor(255, 50, 50)`
  - `_accepted: bool = False`
  - `_fade_in_progress: float = 0.0` (0.0 to 1.0, controls center-outward fade-in)
  - `_raindrops: list[_Raindrop] = []`

  - `_raindrop_spawn_timer: float = 0.0`
  - `self.setZValue(45)` (below BboxLayer at 50)

  - `r = max(self._radius_x, self._radius_y) + 20` (padding for raindrop overflow)
  - Return `QRectF(self._center.x() - r, self._center.y() - r, r * 2, r * 2)`

  - `_center = QPointF(x, y)`
  - `self.prepareGeometryChange()`

- `@property fade_in_progress(self) -> float`: Return `_fade_in_progress`

- `tick(self, dt: float) -> None`:
  - Advance fade-in: `_fade_in_progress = min(1.0, _fade_in_progress + dt * 2.0)` (0.5s full fade-in)
  - Smooth color transition: lerp each channel of `_color` toward `_target_color` by `min(1.0, dt * 3.0)`
  - Advance existing raindrops, remove completed ones: `_raindrops = [r for r in _raindrops if r.tick(dt)]`
  - Spawn new raindrops: `_raindrop_spawn_timer += dt`, if timer > 0.3 and `len(_raindrops) < _max_raindrops`:
    - Generate random position weighted toward center using Gaussian: `angle = random.uniform(0, 2*pi)`, `dist = abs(random.gauss(0, radius * 0.3))`, position = center + (cos(angle)*dist, sin(angle)*dist)
    - Create `_Raindrop(pos, max_radius=15+random.random()*20)`
    - Reset spawn timer
  - Call `self.update()` (safe: from tick, not paint)

- `paint(self, painter: QPainter, option: QStyleOptionGraphicsItem, widget: QWidget | None = None) -> None`:
  - **NO self.update() in this method**
  - Draw main heat map blob using QRadialGradient:
    - `gradient = QRadialGradient(self._center, max(self._radius_x, self._radius_y))`
    - Core stop (0.0): `_color` with alpha `0.8 * _fade_in_progress * 0.6`
    - Mid stop (0.4): `_color` with alpha `0.4 * _fade_in_progress * 0.6`
    - Edge stop (1.0): `_color` with alpha `0.0`
    - `painter.setPen(Qt.PenStyle.NoPen)`
    - `painter.setBrush(gradient)`
    - `painter.drawEllipse(self._center, self._radius_x * _fade_in_progress, self._radius_y * _fade_in_progress)` (fade in from center by scaling radius)
  - Draw each raindrop as an expanding circle:

    - `painter.setBrush(Qt.BrushStyle.NoBrush)`
    - `painter.drawEllipse(raindrop.center, raindrop.radius, raindrop.radius)`
