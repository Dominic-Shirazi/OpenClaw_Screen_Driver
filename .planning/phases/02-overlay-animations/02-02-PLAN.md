**ScanPhase enum:**
```python
class ScanPhase(Enum):
    IDLE = auto()
    CORNER_GLOW = auto()       # Four corners glow red
    LINE_DRAW = auto()         # CCW lines draw from each corner
    FILL_INWARD = auto()       # Red glow fills inward from edges
    LASER_VERTICAL = auto()    # Top-to-bottom scan line
    LASER_HORIZONTAL = auto()  # Left-to-right scan line
    WAITING_AI = auto()        # Loop laser until AI result arrives
    SNAP_TO_FITTED = auto()    # Corners snap to AI bbox
    DONE = auto()
```

**Phase durations dict:**
```python
_PHASE_DURATIONS: dict[ScanPhase, float] = {
    ScanPhase.CORNER_GLOW: 0.3,
    ScanPhase.LINE_DRAW: 0.8,
    ScanPhase.FILL_INWARD: 0.4,
    ScanPhase.LASER_VERTICAL: 1.0,
    ScanPhase.LASER_HORIZONTAL: 1.0,
    ScanPhase.SNAP_TO_FITTED: 0.5,
}
```

**ScanLayer class (QGraphicsObject):**
- `__init__(self, x: int, y: int, w: int, h: int) -> None`:
  - Store `_scan_rect = QRectF(x, y, w, h)` (rough snip boundary)
  - `_fitted_rect: QRectF | None = None` (AI-fitted bbox, set later)
  - `_phase: ScanPhase = ScanPhase.IDLE`
  - `_phase_progress: float = 0.0` (0.0 to 1.0 within current phase)
  - `_ai_ready: bool = False` (set True when AI result arrives)
  - `self.setZValue(60)` (above BboxLayer at 50)
  - Red glow color: `_glow_color = QColor(255, 50, 50)` (from STATE_COLORS RECORDING)

- `boundingRect(self) -> QRectF`: Return `_scan_rect` adjusted outward by 20px for glow overflow

- `start_scan(self) -> None`: Set `_phase = ScanPhase.CORNER_GLOW`, `_phase_progress = 0.0`, `_ai_ready = False`. Call `self.update()`.

- `receive_fitted_bbox(self, x: int, y: int, w: int, h: int) -> None`:
  - Store `_fitted_rect = QRectF(x, y, w, h)`
  - Set `_ai_ready = True`
  - If currently in WAITING_AI or laser phases, transition to SNAP_TO_FITTED

- `reset(self) -> None`: Set `_phase = ScanPhase.IDLE`, `_phase_progress = 0.0`, `_fitted_rect = None`, `_ai_ready = False`. Call `self.update()`.

- `@property phase(self) -> ScanPhase`: Return `_phase`

- `tick(self, dt: float) -> None`:
  - If `_phase in (ScanPhase.IDLE, ScanPhase.DONE)`: return
  - Get duration from `_PHASE_DURATIONS.get(self._phase, 1.0)`
  - Advance: `self._phase_progress += dt / duration`
  - If `self._phase_progress >= 1.0`: call `_advance_phase()`
  - Call `self.update()` (safe: from tick, not paint)

- `_advance_phase(self) -> None`:
  - `_phase_progress = 0.0`
  - Transition map: CORNER_GLOW->LINE_DRAW, LINE_DRAW->FILL_INWARD, FILL_INWARD->LASER_VERTICAL, LASER_VERTICAL->LASER_HORIZONTAL
  - LASER_HORIZONTAL: if `_ai_ready` then SNAP_TO_FITTED, else WAITING_AI
  - WAITING_AI: back to LASER_VERTICAL (loop)
  - SNAP_TO_FITTED->DONE

- `paint(self, painter: QPainter, option: QStyleOptionGraphicsItem, widget: QWidget | None = None) -> None`:
  - **NO self.update() in this method**
  - Switch on `_phase`:
  - **CORNER_GLOW**: Draw 4 glowing red circles/squares at corners of `_scan_rect`, alpha fades in with `_phase_progress`
  - **LINE_DRAW**: Draw lines CCW from each corner toward next corner. Each line's visible length = `_phase_progress * edge_length`. Use red pen with 2px width and glow (paint twice: once with 6px alpha-50 pen for glow, once with 2px full pen for core)
  - **FILL_INWARD**: Draw semi-transparent red fill (30-40% opacity) that grows inward from edges. Inner margin = `max_inset * (1.0 - _phase_progress)` where max_inset is half the smaller dimension
  - **LASER_VERTICAL**: Draw horizontal line at y-position = `_scan_rect.top() + _scan_rect.height() * _phase_progress`. Line style: white core (2px, alpha 220) + red glow halo (6px, alpha 80)
  - **LASER_HORIZONTAL**: Same but vertical line at x-position sweeping left to right
  - **SNAP_TO_FITTED**: Interpolate corners from `_scan_rect` to `_fitted_rect` by `_phase_progress` using ease-in-out. Draw outline at interpolated rect.
  - **IDLE/DONE**: Paint nothing

**Changes to BboxLayer:**

Add imports at top:
```python
from PyQt6.QtCore import QEasingCurve, QPropertyAnimation, QVariant, pyqtProperty, pyqtSignal
from PyQt6.QtWidgets import QGraphicsObject
```

The challenge: BboxLayer currently inherits from QGraphicsItemGroup which is NOT a QObject, so QPropertyAnimation cannot target it directly. Two approaches:

**Approach: Convert BboxLayer to inherit from QGraphicsObject instead of QGraphicsItemGroup.**

This is a bigger change but aligns with the Phase 2 pattern (all animated items use QGraphicsObject). The child items (rect, handles, label) become children managed manually rather than via QGraphicsItemGroup.

Alternatively: Keep QGraphicsItemGroup and use a helper QObject to own the animation properties, driving the group's children via timer ticks.

**Recommended approach (simpler, less breakage):** Add a `morph_to()` method that uses a standalone `QPropertyAnimation` targeting a helper `QObject` subclass that holds the morph progress (0.0 to 1.0), and on each value change updates the rect item and handle positions.

Add an inner class or module-level class:
```python
class _MorphHelper(QObject):
    def __init__(self, bbox_layer: BboxLayer) -> None:
        super().__init__()
        self._bbox = bbox_layer
        self._progress = 0.0

    @pyqtProperty(float)
    def progress(self) -> float:
        return self._progress

    @progress.setter
    def progress(self, value: float) -> None:
        self._progress = value
        self._bbox._apply_morph_progress(value)
```

**New methods on BboxLayer:**

- `morph_to(self, x: int, y: int, w: int, h: int, duration_ms: int = 500) -> None`:
  - Store `_morph_start = (self._x, self._y, self._w, self._h)`
  - Store `_morph_end = (x, y, w, h)`
  - Create `_morph_helper = _MorphHelper(self)` if not exists
  - Create `_morph_anim = QPropertyAnimation(self._morph_helper, b"progress")`
  - Set duration to `duration_ms`, easing to `QEasingCurve.Type.InOutCubic`
  - Set start value 0.0, end value 1.0
  - Connect `finished` signal to `_on_morph_done`
  - Start animation
  - Set `_is_morphing = True`

- `_apply_morph_progress(self, t: float) -> None`:
  - Interpolate x, y, w, h: `val = start + (end - start) * t` for each
  - Update `self._rect.setRect(QRectF(ix, iy, iw, ih))`
  - Update handle positions using `_corner_positions(ix, iy, iw, ih)`
  - Update label position if label exists
  - Store interpolated values in `_x, _y, _w, _h` so `get_rect()` stays accurate

- `_on_morph_done(self) -> None`:
  - `_is_morphing = False`
  - Ensure final values exactly match target (no floating point drift)

- `@property is_morphing(self) -> bool`: Return `_is_morphing`

- Add `morph_finished = pyqtSignal()` -- no wait, BboxLayer is QGraphicsItemGroup which is not QObject. Use a callback instead: `on_morph_done: Callable[[], None] | None` parameter or just a flag.

**After morph final state styling:**
- After morph completes, update pen to thin red outline (1px) with dimmed glow (per CONTEXT.md: "thin red outline, glow retreats")
- Set brush to `QColor(255, 50, 50, 20)` (very faint red fill)
