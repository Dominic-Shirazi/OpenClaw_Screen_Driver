Create `recorder/overlay/shimmer_layer.py` with class `ShimmerLayer(QGraphicsObject)`:

```python
from __future__ import annotations
import logging
import math
from PyQt6.QtCore import QPointF, QRectF, Qt
from PyQt6.QtGui import QColor, QConicalGradient, QPainter, QPainterPath
from PyQt6.QtWidgets import QGraphicsObject, QStyleOptionGraphicsItem, QWidget
from recorder.overlay.state import STATE_COLORS, OverlayState

logger = logging.getLogger(__name__)

# Border width per state
_BORDER_READY: int = 16
_BORDER_RECORDING: int = 10
_RETREAT_RADIUS: float = 200.0
```

**ShimmerLayer class (QGraphicsObject):**
- `__init__(self, screen_w: int, screen_h: int) -> None`:
  - `super().__init__()`
  - Store `_screen_w`, `_screen_h`
  - `_phase: float = 0.0` (0.0 to 1.0, maps to 0-360 degrees)
  - `_loop_duration: float = 5.0` (seconds for one full rotation)
  - `_border_width: float = _BORDER_READY`
  - `_target_border_width: float = _BORDER_READY`
  - `_base_color: QColor = QColor(50, 200, 50)` (green default)
  - `_mouse_pos: QPointF = QPointF(-1000, -1000)` (offscreen initially)
  - `_avoidance_rects: list[QRectF] = []`
  - `self.setZValue(10)` (same as old BorderLayer)
  - `self.setFlag(QGraphicsObject.GraphicsItemFlag.ItemHasNoContents, False)`

- `boundingRect(self) -> QRectF`: Return `QRectF(0, 0, self._screen_w, self._screen_h)`

- `set_state(self, state: OverlayState) -> None`:
  - Extract RGBA from `STATE_COLORS[state]`, set `_base_color = QColor(r, g, b)`
  - If `state == OverlayState.RECORDING`: `_loop_duration = 2.0`, `_target_border_width = _BORDER_RECORDING`
  - Else: `_loop_duration = 5.0`, `_target_border_width = _BORDER_READY`

- `set_mouse_pos(self, x: float, y: float) -> None`: Store `_mouse_pos = QPointF(x, y)`

- `set_avoidance_rects(self, rects: list[QRectF]) -> None`: Store `_avoidance_rects = list(rects)`

- `tick(self, dt: float) -> None`:
  - Advance phase: `self._phase = (self._phase + dt / self._loop_duration) % 1.0`
  - Smooth border width transition: `self._border_width += (self._target_border_width - self._border_width) * min(1.0, dt * 4.0)`
  - Call `self.update()` (safe: called from tick, NOT from paint)

- `_shimmer_intensity_at(self, px: float, py: float) -> float`:
  - Calculate distance from `_mouse_pos` using `math.hypot`
  - Also calculate minimum distance to any `_avoidance_rects` (use rect center distance minus half-diagonal as approximation, or use `QRectF` API)
  - Take the minimum distance from mouse and avoidance rects
  - If `dist >= _RETREAT_RADIUS`: return `1.0`
  - Else: `t = dist / _RETREAT_RADIUS`, return `t * t * (3.0 - 2.0 * t)` (smoothstep)

- `paint(self, painter: QPainter, option: QStyleOptionGraphicsItem, widget: QWidget | None = None) -> None`:
  - **CRITICAL: No self.update() call in this method**
  - Build border clip path: outer rect - inner rect (adjusted by `_border_width` on all sides)
  - Create `QConicalGradient` centered on screen center, angle = `_phase * 360.0`
  - Set gradient stops: bright color at 0.0/0.5/1.0, dim color at 0.25/0.75 (same pattern as RESEARCH.md example)
  - `painter.save()`, `painter.setClipPath(border_path)`, `painter.fillRect(bounding_rect, gradient)`
  - For mouse retreat effect: sample 8-16 points around the border perimeter, calculate intensity at each, modulate alpha of a secondary darkening pass at low-intensity regions using `painter.setCompositionMode(QPainter.CompositionMode.CompositionMode_DestinationIn)` or by painting semi-transparent black rectangles over retreated areas
  - Simpler approach: divide border into 32 segments, calculate shimmer_intensity_at() for each segment center, draw each segment with alpha scaled by intensity. Use `QPainterPath` segments clipped from the border strip.
  - `painter.restore()`
