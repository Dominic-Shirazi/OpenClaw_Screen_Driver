**2. Create `recorder/overlay/pipeline_bridge.py`:**
```python
class PipelineBridge(QObject):
    """Thread-safe signal bridge for recording pipeline results."""
    detection_ready = pyqtSignal(dict)     # {bbox: {x,y,w,h}, candidates: [...], type_guess: str}
    vlm_ready = pyqtSignal(dict)           # {element_type, label_guess, confidence, ocr_text, caption}
    vlm_failed = pyqtSignal(str)           # error message
    execution_complete = pyqtSignal()      # dry-run action finished (emitted from background thread, received on main thread)
    save_complete = pyqtSignal(str)        # routine directory path
    save_failed = pyqtSignal(str)          # error message
```
Subclass QObject. Import from `PyQt6.QtCore`. Include type hints and docstrings on all signals.

IMPORTANT: `execution_complete` is critical for thread-safe dry-run completion. Background execution threads MUST emit `self._bridge.execution_complete.emit()` after the action finishes. Qt's signal-slot mechanism guarantees delivery on the main thread when connected via default (AutoConnection). Do NOT use QTimer.singleShot from a background thread -- it is not thread-safe.
