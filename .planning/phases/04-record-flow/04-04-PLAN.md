**1. Dry-run countdown (on_tag_confirmed -> COUNTDOWN):**

In `on_tag_confirmed(data: dict)`:
1. Store step data in `self._current_step` (merge tag dialog data with bbox data)
2. Dismiss tag dialog: `self._controller.dismiss_tag_dialog()`
3. Set phase to COUNTDOWN
4. Set toolbar mode to DRY_RUN
5. Show countdown: `widget = self._controller.show_countdown(3)`
6. Connect `widget.countdown_finished` to `self._on_countdown_finished`

**2. Dry-run execution (COUNTDOWN -> EXECUTING):**

`_on_countdown_finished()`:
1. Hide countdown: `self._controller.hide_countdown()`
2. Set phase to EXECUTING
3. Set overlay to click-through: `self._controller.set_click_through(True)`
4. Execute the action in a background thread using `threading.Thread(daemon=True)`:
   - Import `core.executor` and call the appropriate action (click for now)
   - For click action: `executor.click(bbox_center_x, bbox_center_y)`
   - After execution: use QTimer.singleShot(0, self._on_execution_complete) via bridge or main-thread callback
5. Note: Mouse is NOT locked during this -- per REC-09, only countdown + execution, cursor is free

`_on_execution_complete()`:
1. Restore click-through: `self._controller.set_click_through(False)`
2. Set phase to VALIDATING
3. Set toolbar mode to VALIDATING

**3. Validation toolbar actions (VALIDATING -> next):**

In `on_toolbar_action`, handle VALIDATING mode actions:

- `"yes"`:
  1. Lock step: append `self._current_step` to `self._steps` with `dry_run_passed=True`
  2. Set phase to SUCCESS_FLASH
  3. Flash success on the bbox: `self._controller.flash_success(QRectF(bbox_x, bbox_y, bbox_w, bbox_h))`
  4. Clear scan/bbox/donut from overlay
  5. After 500ms (QTimer.singleShot), set phase to AWAITING_CLICK, set toolbar to RECORDING
  6. This is the loop-back (REC-10)

- `"edit_tags"`:
  1. Reopen tag dialog with current step data: `self._controller.show_tag_dialog(rect, vlm_data=current_step, edit_mode=True)`
  2. Set phase to TAG_DIALOG, toolbar to TAG_OPEN

- `"recapture"`:
  1. Discard current step entirely
  2. Clear scan/bbox/donut from overlay
  3. Set phase to AWAITING_CLICK, toolbar to RECORDING

- `"retry"`:
  1. Set phase to COUNTDOWN again
  2. Show countdown again (full 3-2-1 replay per CONTEXT.md)

**4. Save flow (on_save_requested -> save to disk):**

`on_save_requested()`:
1. If `len(self._steps) == 0`: close overlay silently (no confirmation needed per CONTEXT.md)
2. Otherwise, save in background thread:

`_save_routine()` (background thread):
1. Create save directory: `~/.ocsd/routines/{self._routine_name}/` with `snippets/` and `embeddings/` subdirs
2. Build OCSDGraph from steps (adapt from record_controller._save_recording):
   - For each step: add_node with element_type, label, x_pct, y_pct, w_pct, h_pct
   - Connect nodes with sequential edges
3. Save snippets and embeddings (adapt from record_controller._save_snippets_and_embeddings):
   - For each step with bbox: crop + 30% padding, save PNG, generate CLIP embedding
4. Build interim routine.json (per RESEARCH recommended format):
```python
routine_data = {
    "$schema": "ocsd-routine-v0",
    "name": self._routine_name,
    "description": f"Recorded routine: {self._routine_name}",
    "start_from": self._start_from,
    "created_at": datetime.now(timezone.utc).isoformat(),
    "resolution": [screen_w, screen_h],
    "steps": [step_to_json(s, i) for i, s in enumerate(self._steps)],

```
5. Write routine.json to save_dir
6. Emit `self._bridge.save_complete.emit(str(save_dir))` on success
7. Emit `self._bridge.save_failed.emit(str(error))` on failure

`_on_save_complete(path: str)`:
1. Log success
2. Flash "Saved" on mode indicator (1s)
3. Close overlay: `self._controller.close()`

`_on_save_failed(error: str)`:
1. Log error
2. Show error on overlay (use abort panel or similar with retry option)
3. Do NOT lose session data

**5. Abort flow (on_abort_requested):**

`on_abort_requested()`:
1. If `len(self._steps) == 0`: close overlay silently, no confirmation
2. Otherwise: show abort confirmation panel: `panel = self._controller.show_abort_confirm(len(self._steps))`
3. Connect `panel.discard_clicked` to `self._on_abort_confirmed`
4. Connect `panel.keep_clicked` to `self._on_abort_cancelled`

`_on_abort_confirmed()`:
1. Discard all in-memory session data (`self._steps.clear()`)
2. Close overlay: `self._controller.close()`

`_on_abort_cancelled()`:
1. Hide abort panel: `self._controller.hide_abort_confirm()`
2. Return to previous phase (AWAITING_CLICK)

**1. Create `recorder/record_flow.py`:**

New entry point `cmd_record(routine_name: str | None = None) -> int` that replaces the legacy `record_controller.cmd_record()`.

```python
"""Record flow entry point: TUI naming -> overlay -> recording session.

This module provides the new V2 recording entry point that uses the
overlay-integrated pipeline (Phase 1-4) instead of the legacy modal
dialog flow.
"""
from __future__ import annotations

import logging
import sys
from pathlib import Path

logger = logging.getLogger(__name__)


def _prompt_routine_name() -> tuple[str, str] | None:
    """Prompt user for routine name and start-from choice via Rich TUI.

    Returns:
        Tuple of (routine_name, start_from) or None if user cancelled.
    """
    try:
        from rich.console import Console
        from rich.prompt import Prompt, Confirm
    except ImportError:
        # Fallback to input() if Rich not available
        name = input("Routine name: ").strip()
        if not name:
            print("Name cannot be empty.")
            return None
        start_from = input("Does this routine start from the desktop or an already-open app? [d/a] ").strip().lower()
        start_from = "desktop" if start_from != "a" else "app"
        return (name, start_from)

    console = Console()
    name = Prompt.ask("Routine name")
    if not name or not name.strip():
        console.print("[red]Name cannot be empty.[/red]")
        return None
    name = name.strip()

    # Check for existing routine
    routines_dir = Path.home() / ".ocsd" / "routines" / name
    if routines_dir.exists():
        overwrite = Confirm.ask(
            f'Routine "{name}" already exists. Overwrite?', default=False,
        )
        if not overwrite:
            return None

    start_from_choice = Prompt.ask(
        "Does this routine start from the desktop or an already-open app?",
        choices=["d", "a"],
        default="d",
    )
    start_from = "desktop" if start_from_choice == "d" else "app"

    return (name, start_from)


def cmd_record(routine_name: str | None = None) -> int:
    """Launch a new recording session.

    If routine_name is not provided, prompts the user via Rich TUI.
    Sets up the overlay, creates a RecordSession, and runs the Qt
    event loop until the session completes (save or abort).

    Args:
        routine_name: Optional pre-set routine name (skip TUI prompt).

    Returns:
        Process exit code (0 = success, 1 = error/abort).
    """
    from PyQt6.QtWidgets import QApplication

    from recorder.overlay.controller import OverlayController
    from recorder.overlay.toolbar_panel import ToolbarMode
    from recorder.platform_utils import minimize_all_windows
    from recorder.record_session import RecordSession

    # Step 1: Get routine name (TUI prompt or provided)
    start_from = "desktop"
    if routine_name is None:
        result = _prompt_routine_name()
        if result is None:
            return 1
        routine_name, start_from = result

    # Step 2: Create QApplication
    app = QApplication.instance() or QApplication(sys.argv)
    app.setQuitOnLastWindowClosed(False)

    # Step 3: Minimize windows if starting from desktop
    if start_from == "desktop":
        success = minimize_all_windows()
        if not success and sys.platform == "win32":
            # On Windows, warn but allow continue
            try:
                from rich.console import Console
                from rich.prompt import Confirm
                console = Console()
                console.print("[yellow]Some windows could not be minimized.[/yellow]")
                if not Confirm.ask("Continue anyway?", default=True):
                    return 1
            except ImportError:
                response = input("Some windows could not be minimized. Continue anyway? [Y/n] ").strip().lower()
                if response == "n":
                    return 1

    logger.info("Starting recording session: %s (start_from=%s)", routine_name, start_from)

    # Step 4: Create controller and session
    exit_code = 0

    def on_session_complete(success: bool) -> None:
        nonlocal exit_code
        exit_code = 0 if success else 1
        app.quit()

    controller = OverlayController(
        on_save=lambda: None,  # RecordSession will handle
        on_abort=lambda: None,  # RecordSession will handle
    )

    session = RecordSession(
        controller=controller,
        routine_name=routine_name,
        start_from=start_from,
    )

    # Step 5: Pre-load detection models
    try:
        from core.detection import get_detector
        get_detector()
    except (ImportError, RuntimeError, OSError) as e:
        logger.warning("Detection models not available: %s", e)

    # Step 6: Show overlay and start session
    controller.show()
    session.start()

    # Step 7: Run event loop
    app.exec()

    return exit_code
```
