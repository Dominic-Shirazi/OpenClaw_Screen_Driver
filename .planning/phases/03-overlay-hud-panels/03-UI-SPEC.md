# Phase 3 — UI Design Contract

> Visual and interaction contract for overlay HUD panels. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (PyQt6 desktop overlay, not web) |
| Preset | not applicable |
| Component library | PyQt6 QGraphicsScene + QGraphicsProxyWidget |
| Icon library | none (text labels on toolbar buttons) |
| Font | Segoe UI (Windows), system sans-serif fallback |

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding within input fields |
| sm | 8px | Field-to-label spacing, button internal padding, input field horizontal padding |
| md | 16px | Internal panel padding (left/right/top margins), gap between element bbox and tag dialog |
| lg | 24px | Section spacing within tag dialog (between field groups), breathing room from screen edges |

Exceptions: 15px corner radius on panels (not a spacing token, a shape property).

---

## Typography

All fonts use Segoe UI on Windows with system sans-serif fallback. Font weight 300 (light/thin) is the primary weight per CONTEXT.md "thin white fonts on dark frost."

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Helper tip | 10px | 300 (light) | 1.3 | Dimmed contextual tips below fields |
| Field label / Toolbar button | 12px | 400 (regular) | 1.3 | Labels above input fields, toolbar button text |
| Field input / Section heading | 14px | 300 (light) | 1.4 | Text inside QLineEdit and QComboBox, tag dialog title if needed |

---

## Color

All colors specified as RGBA tuples matching the existing codebase convention (STATE_COLORS pattern).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | rgba(15, 15, 25, 200) | Frosted glass panel background fill |
| Secondary (30%) | rgba(20, 20, 35, 220) | Recessed input field wells, toolbar background |
| Accent (10%) | rgba(50, 200, 50, *) | See reserved-for list below |
| Destructive | rgba(255, 50, 50, *) | Not used in this phase (no destructive actions in HUD panels) |
| Text primary | rgba(240, 240, 245, 230) | Input field text, selected dropdown text |
| Text secondary | rgba(200, 200, 210, 150) | Field labels, placeholder text, helper tips |
| Text disabled | rgba(140, 140, 150, 80) | Disabled field text |
| Border subtle | rgba(50, 200, 50, 60) | Input field borders (1px) |
| Highlight gradient top | rgba(255, 255, 255, 12) | Frosted glass inner highlight at top edge |

Accent reserved for:
- Card border glow lights (24 radial gradient sources around panel perimeter)
- Confirm button background and text
- Input field border (subtle, 60 alpha)
- Typewriter cursor blink (blinking green rectangle at insertion point)
- Toolbar pill glow (same card glow technique)
- Shimmer glow interaction (existing shimmer retreats from HUD panels)

## Panel Specifications

### Tag Dialog Panel

Primary focal point: the Label field -- it is the first field the user sees and the most important metadata for the captured element.

| Property | Value | Source |
|----------|-------|--------|
| Default size | 400 x 280px | CONTEXT.md locked decision |
| Corner radius | 15px | CONTEXT.md (14-16px, using 15) |
| Background | rgba(15, 15, 25, 200) | RESEARCH.md frosted glass pattern |
| Border glow | 24 radial gradient lights, 30px radius each, CompositionMode_Plus | RESEARCH.md card glow pattern |
| Glow idle animation | Slow shimmer sweep (same algorithm as ShimmerLayer) | CONTEXT.md |
| Glow typing animation | Brightness pulses synchronized with character insertion | CONTEXT.md |
| Z-value | 100 | RESEARCH.md (above all animation layers) |
| Fade-in duration | 200ms, ease-out | Default |
| Fade-out duration | 150ms, ease-in | Default |
| Positioning | Prefer below-right of captured element, flip if near edge, 24px breathing room from screen edges, 16px gap from element | CONTEXT.md + RESEARCH.md |

### Tag Dialog Fields

| Field | Widget | VLM Auto-fill | Conditional On |
|-------|--------|---------------|----------------|
| Label | QLineEdit | Yes (typewriter) | Always visible |
| Caption | QLineEdit | Yes (typewriter) | Always visible |
| Action Type | QComboBox | Yes (instant) | Always visible |
| Element Type | QComboBox | Yes (instant) | Always visible |
| Text to type | QLineEdit | No | action_type == "type" |
| Press Enter after? | QCheckBox | No | action_type == "type" |
| Direction/Amount | QLineEdit | No | action_type == "scroll" |
| Condition/Timeout | QLineEdit | No | action_type == "wait" |
| Drag target hint | QLineEdit | No | action_type == "click_drag" |
| VLM prompt | QLineEdit | No | action_type in ("read", "snip_and_search") |
| Question text | QLineEdit | No | action_type == "prompt_user" |

### Tag Dialog Buttons

| Button | Label | Color | Shortcut |
|--------|-------|-------|----------|
| Confirm | "Confirm" | Green fill rgba(50, 200, 50, 180), white text | Enter |
| Dismiss | "Dismiss" | Dim fill rgba(60, 60, 70, 150), dim text rgba(180, 180, 190, 180) | Esc |

| Property | Value | Source |
|----------|-------|--------|

### Toolbar Context Modes

| Mode | Buttons | Source |
|------|---------|--------|
| RECORDING | [Pause] [Undo Last] | CONTEXT.md |
| TAG_OPEN | [Confirm] [Dismiss] [Skip] | CONTEXT.md |
| DRY_RUN | [Run Step] [Skip Step] [Finish] | CONTEXT.md |

Button swap transition: 150ms cross-fade (fade out old, fade in new simultaneously).

## Typewriter Engine

| Property | Value | Source |
|----------|-------|--------|
| Speed range | 30-50ms per character (20-33 chars/sec) | CONTEXT.md |
| Fill duration | 1-2 seconds for typical labels | CONTEXT.md |
| Per-field variation | Each field gets a random speed within range | CONTEXT.md "different speeds" |
| Simultaneous fill | All VLM fields typewrite at once | CONTEXT.md |
| Cursor | Blinking green rectangle (500ms blink interval) at insertion point per field | CONTEXT.md |
| Glow sync | Card border brightness pulses on each character insertion | CONTEXT.md |
| User interrupt | textEdited signal stops typewriter for that field immediately | RESEARCH.md pitfall 4 |
| Edit mode | Pre-fill all fields instantly, no typewriter, no cursors | CONTEXT.md HUD-03 |
| VLM waiting | Card glow pulses/breathes (no spinner), cursor blinks at current position | CONTEXT.md |
| VLM timeout | Fields become editable with whatever text has been filled so far | CONTEXT.md |

## Interaction States

### Tag Dialog Lifecycle

| State | Visual | Trigger |
|-------|--------|---------|
| Hidden | Not in scene | Default |
| Appearing | Fade in (0 to 1 opacity, 200ms) | Controller calls show_tag_dialog() |
| VLM Waiting | Card glow breathing, cursors blinking, fields empty | VLM processing |
| Typewriting | All fields filling simultaneously, glow pulses with keystrokes | VLM returns data |
| Editable | All fields filled, glow returns to idle sweep, user can edit | Typewriter completes or user interrupts |
| Pre-filled (edit) | Fields instantly populated, no typewriter, idle glow | show_tag_dialog(edit_mode=True) |
| Dismissing | Fade out (1 to 0 opacity, 150ms) | Confirm or Dismiss |

### Toolbar Lifecycle

| State | Visual | Trigger |
|-------|--------|---------|
| Hidden | Not visible | Before recording starts |
| Visible | Pill bar with mode-appropriate buttons | Recording starts |
| Mode switching | 150ms cross-fade between button sets | State change |
| Dragging | Follows mouse, clamped to screen | User drags |
| Capture hidden | Fully invisible (setVisible(False), opacity 0) | hide_for_capture() |

### Focus Management

| State | Click-through | Focus target |
|-------|--------------|--------------|
| Tag dialog open | OFF (overlay captures input) | First QLineEdit via proxy.setFocus() |
| Tag dialog closed | Restored to previous state | None |
| Toolbar only | ON (clicks pass through to desktop) | None |

## Integration Contracts

### Shimmer Avoidance

Both panels MUST call `shimmer.set_avoidance_rects()` with their scene bounding rects:
- Tag dialog: on show, on resize, on dismiss (remove rect)
- Toolbar: on show, on drag (itemChange ItemPositionHasChanged), on hide (remove rect)

### Hide for Capture

Both panels MUST be hidden in `OverlayView.hide_for_capture()`:
- Force opacity to 0
- Force setVisible(False)
- Do NOT rely on animation completing
- Restore in `show_after_capture()`

### Controller API Extensions

| Method | Purpose |
|--------|---------|
| show_tag_dialog(element_rect, vlm_data, edit_mode) | Show tag dialog near element with optional VLM data |
| dismiss_tag_dialog() | Fade out and remove tag dialog |
| get_tag_data() -> dict | Return current form field values |
| show_toolbar() | Show floating toolbar |
| hide_toolbar() | Hide floating toolbar |
| set_toolbar_mode(mode: ToolbarMode) | Switch toolbar button set |
