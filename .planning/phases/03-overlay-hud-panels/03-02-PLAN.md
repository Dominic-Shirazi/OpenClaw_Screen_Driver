Create `recorder/overlay/tag_dialog_panel.py` implementing a frosted-glass tag dialog as a QGraphicsObject in the scene.

**Class: TagDialogPanel(QGraphicsObject)**

Signals:
- `confirmed = pyqtSignal(dict)` -- emitted with form data dict when user confirms
- `dismissed = pyqtSignal()` -- emitted when user dismisses

Constructor `__init__(self, clock: AnimationClock, parent: QGraphicsObject | None = None)`:
- Set z-value to `Z_TAG_DIALOG` (100)
- Initialize `_width = 400.0`, `_height = 280.0`, `_corner_radius = CORNER_RADIUS` (15.0)
- Initialize `_opacity = 0.0` for fade animation
- Initialize `_glow_phase = 0.0` for card border glow sweep
- Initialize `_glow_brightness = 1.0` for typing-synchronized pulses
- Create `_typewriter = TypewriterEngine(clock, parent=self)`
- Connect `_typewriter.char_inserted` to `_on_char_inserted` (flash glow brightness to 2.0)
- Connect `_typewriter.finished` to `_on_typewriter_done`
- Store `_clock = clock` and register `self._tick` callback
- Create all form widgets via `_create_fields()`:

**Form fields (all embedded via QGraphicsProxyWidget as children of self):**

Always-visible fields:
1. **Label** QLineEdit -- placeholder "Element label...", position y=~30
2. **Caption** QLineEdit -- placeholder "What this element does...", position y=~70
3. **Action Type** QComboBox -- populated with: click, double_click, right_click, click_drag, type, scroll, wait, read, snip_and_search, select_all_extract, loop, prompt_user. Default "click"
4. **Element Type** QComboBox -- populated from `_TYPE_GROUPS` in recorder/dialog.py (reuse the same grouping with disabled separator headers). Default "unknown"

Conditional fields (shown/hidden based on Action Type selection):
5. **Text to type** QLineEdit -- visible when action_type == "type". Placeholder "Text to enter..."
6. **Press Enter after?** QCheckBox -- visible when action_type == "type". Label text "Press Enter to send?"
7. **Direction/Amount** QLineEdit -- visible when action_type == "scroll". Placeholder "Direction and pixel amount to scroll"
8. **Condition/Timeout** QLineEdit -- visible when action_type == "wait". Placeholder "Condition to wait for, or timeout in seconds"
9. **Drag target hint** QLineEdit -- visible when action_type == "click_drag". Placeholder "I'll capture the drag destination after you confirm this step"
10. **VLM prompt** QLineEdit -- visible when action_type in ("read", "snip_and_search"). Placeholder "What to look for..."
11. **Question text** QLineEdit -- visible when action_type == "prompt_user". Placeholder "Question for the user..."

Bottom buttons:
12. **Confirm** QPushButton -- text "Confirm", green background `rgba(50, 200, 50, 180)`, white text, Enter shortcut
13. **Dismiss** QPushButton -- text "Dismiss", dim background `rgba(60, 60, 70, 150)`, dim text `rgba(180, 180, 190, 180)`, Esc shortcut

Helper tips (QLabel via proxy, dimmed TEXT_SECONDARY color, 10px font):
- For "type" action: "I'll click here before typing -- no need for a separate click step"
- For "type" + checkbox: "Press Enter to send? Common for search boxes and chat inputs"
- For "scroll": "Direction and pixel amount to scroll"
- For "wait": "Condition to wait for, or timeout in seconds"
- For "click_drag": "I'll capture the drag destination after you confirm this step"
- For "read"/"snip_and_search": "Describe what you want to extract from this area"
- For "prompt_user": "This question will be shown to the user or agent during replay"

All QLineEdit and QComboBox widgets get `FIELD_STYLESHEET` from hud_common. All labels get TEXT_SECONDARY color and FONT_SIZE_LABEL size.

**Method: _create_field(widget, x, y, width) -> QGraphicsProxyWidget**
Helper that applies stylesheet, sets fixed width, creates QGraphicsProxyWidget as child of self, positions it.

**Method: _create_label(text, x, y) -> QGraphicsProxyWidget**
Helper for field labels above inputs. Uses FONT_SIZE_LABEL, TEXT_SECONDARY color, transparent background.

**Action type change handler: _on_action_type_changed(index)**
- Get current action type string from combo data
- Show/hide conditional fields based on action type
- Show/hide helper tips based on action type
- Call `_relayout_fields()` to reposition all visible fields and resize panel height
- Animate panel height change: use `_target_height` and interpolate in `_tick()`

**Method: _relayout_fields()**
- Calculate total height based on visible fields: base 280px + extra per conditional field (~40px each)
- Reposition all visible proxy widgets vertically, stacking them with SPACING.sm (8px) gaps
- Set `_target_height` and let `_tick()` interpolate `_height` smoothly

**Method: show_dialog(element_rect: QRectF, vlm_data: dict | None = None, edit_mode: bool = False)**
- Compute position via `_compute_position()` (prefer below-right of element_rect, flip if near edge, 24px breathing room)
- Set self position with `setPos(x, y)`
- If edit_mode: set all field values directly from vlm_data, no typewriter. Set _opacity to 0 and animate to 1.0 (200ms fade-in via _tick interpolation)
- If not edit_mode and vlm_data provided: start typewriter for label, caption fields. Set action_type and element_type combos instantly (dropdowns don't typewrite). Set _opacity to 0 and animate to 1.0
- If not edit_mode and no vlm_data: show empty fields, animate fade-in
- Emit avoidance rect update via `_update_avoidance_rect()` (callable stored from caller)

**Method: _compute_position(element_rect, screen_w, screen_h) -> tuple[float, float]**
- Prefer below-right: x = element_rect.right() + SPACING.md (16px), y = element_rect.top()
- Flip horizontal if x + _width + SPACING.lg (24px) > screen_w
- Flip vertical if y + _height + SPACING.lg > screen_h
- Clamp: x = max(SPACING.lg, min(x, screen_w - _width - SPACING.lg))
- Clamp: y = max(SPACING.lg, min(y, screen_h - _height - SPACING.lg))

**Method: dismiss()**
- Animate opacity from current to 0 (150ms fade-out via _tick)
- After fade completes, emit `dismissed` signal

**Method: confirm()**
- Collect all form data into dict: {label, caption, action_type, element_type, + conditional field values}
- Emit `confirmed(data)`
- Call dismiss()

**Method: get_form_data() -> dict**
- Returns current form field values as a dict

**Method: get_avoidance_rect() -> QRectF**
- Returns the scene bounding rect of this panel (for shimmer avoidance)

**paint(painter, option, widget):**
1. Save painter, set opacity via `painter.setOpacity(self._opacity)`
2. Paint frosted background: QPainterPath.addRoundedRect, fill with FROST_BG
3. Paint inner highlight gradient at top (HIGHLIGHT_TOP -> transparent over 30% height)
4. Call `paint_card_glow(painter, QRectF(0,0,_width,_height), brightness=_glow_brightness, phase=_glow_phase)`
5. Restore painter

**_tick(dt) callback (registered with AnimationClock):**
1. Advance `_glow_phase = (_glow_phase + dt / 5.0) % 1.0` (slow sweep, 5s period)
2. Decay `_glow_brightness` toward 1.0: `_glow_brightness += (1.0 - _glow_brightness) * min(1.0, dt * 8.0)` (fast decay after typing flash)
3. Interpolate `_opacity` toward `_target_opacity`: `_opacity += (_target_opacity - _opacity) * min(1.0, dt * (1000/FADE_IN_MS))` (approximately)
4. Interpolate `_height` toward `_target_height` for smooth resize
5. Call `self.update()` to schedule repaint

**_on_char_inserted(field_index):**
- Flash `_glow_brightness = 2.0` (will decay in _tick)

**_on_typewriter_done():**
- All fields now editable, glow returns to idle sweep

**Keyboard handling:**
- Override `keyPressEvent`: Enter key -> confirm(), Esc key -> dismiss()
- Connect each QLineEdit's `textEdited` signal to `_on_user_edit(field_index)` which calls `_typewriter.interrupt_field(field_index)` -- stops typewriter for that field when user starts typing

**boundingRect():**
- Return QRectF(-30, -30, _width + 60, _height + 60) -- extra padding for card glow overflow

Use `from __future__ import annotations`, full type hints, Google-style docstrings, `logger = logging.getLogger(__name__)`.
