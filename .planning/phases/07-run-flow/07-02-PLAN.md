```python
class TargetHighlight(QGraphicsObject):
    """Quick purple glow around located element bbox.

    Shows for ~300ms then fades out automatically. Used during replay
    to show which element the system located before executing the action.
    """
```

Key details:
- Constructor takes `(clock: AnimationClock)`
- Method `highlight(x: int, y: int, w: int, h: int) -> None` sets the target rect and starts the fade timer
- Internal state: `_rect: QRectF | None`, `_opacity: float`, `_lifetime: float` (counts up), `_duration: float = 0.3`
- `tick(dt: float)`: if active, increment `_lifetime += dt`. If `_lifetime >= _duration`, set `_opacity = 0`, set `_rect = None`. Otherwise compute `_opacity = 1.0 - (_lifetime / _duration)` for linear fade-out.
- `paint()`: if `_rect` is not None and `_opacity > 0`, draw a rounded rect with:
  - No fill
  - Purple stroke (QColor(160, 80, 220, int(180 * _opacity))), 3px width
  - Also draw a soft purple glow: second rect with 6px stroke at lower alpha (int(60 * _opacity))
- `boundingRect()`: return full screen rect (or `_rect` expanded by 10px if set)
- `setZValue(290)` in constructor (just below status badge)
- Method `hide() -> None` immediately sets `_rect = None`, `_opacity = 0`

```python
class CameraFlash(QGraphicsObject):
    """15px border camera flash effect after screenshot capture.

    Triggered after each screenshot during replay. Shows a bright white
    15px border that fades out over ~200ms, simulating a camera flash.
    The flash confirms to the user/agent that a screenshot was captured.
    """
```

Key details:
- Constructor takes `(clock: AnimationClock, screen_w: int, screen_h: int)`
- `setZValue(280)` in constructor (below target highlight and badge)
- Internal state: `_opacity: float = 0.0`, `_lifetime: float = 0.0`, `_active: bool = False`, `_duration: float = 0.2`
- `_border_width: int = 15`
- Method `flash() -> None`: sets `_opacity = 1.0`, `_lifetime = 0.0`, `_active = True`, calls `self.update()`
- `tick(dt: float)`: if `_active`, increment `_lifetime += dt`. If `_lifetime >= _duration`, set `_active = False`, `_opacity = 0.0`. Otherwise compute `_opacity = 1.0 - (_lifetime / _duration)` for linear fade-out. Call `self.update()`.
- `paint()`: if `_active` and `_opacity > 0`:
  - Draw a 15px-wide border frame around the full screen rect using `QPen` with white color (QColor(255, 255, 255, int(220 * _opacity))), width 15
  - Draw the rect as `drawRect(7.5, 7.5, screen_w - 15, screen_h - 15)` (inset by half border width for correct rendering)
  - No fill, just the border stroke
- `boundingRect()`: return full screen rect `QRectF(0, 0, screen_w, screen_h)`
- Method `hide() -> None`: sets `_active = False`, `_opacity = 0.0`, calls `self.update()`
- Register with AnimationClock in constructor: `clock.register(self.tick)`
