**`preflight_check(routine: Routine, routine_dir: Path) -> list[str]`:**
- Returns list of error strings (empty = passed)
- Check 1: For each step, verify `routine_dir / step["snippet_path"]` exists (if snippet_path set)
- Check 2: For each step, verify `routine_dir / step["embedding_path"]` exists (if embedding_path set)
- Check 3: Test VLM connectivity: try `from core.vision import analyze_crop_array` and send a minimal test (timeout 5s). If fails, add warning (not error -- per CONTEXT.md, VLM unavailable returns status to caller, doesn't abort)
- Return the error list. Warnings are logged but don't appear in the error list.

**`_dispatch_action(step: dict, locate_result: LocateResult, dry_run: bool = False) -> str`:**
- Match on `step["action"]`:
  - `"click"`: `click(point.x, point.y)`. Return "clicked"
  - `"double_click"`: `double_click(point.x, point.y)`. Return "double_clicked"
  - `"right_click"`: `right_click(point.x, point.y)`. Return "right_clicked"
  - `"click_drag"`: Get drag_target from step. Resolve target position from drag_target bbox_pct. `drag(point.x, point.y, tx, ty)`. Return "dragged"
  - `"type"`: `click(point.x, point.y)` then `type_text(step["text_to_type"])`. If `step.get("press_enter")`: `press_enter()`. Return "typed"
  - `"scroll"`: Get scroll dict from step. `scroll(point.x, point.y, scroll["direction"], scroll["amount"])`. Return "scrolled"
  - `"read"`, `"snip_and_search"`: Take screenshot, crop bbox region, call `analyze_crop_array()`. Return result text.
  - `"select_all_extract"`: `click(point.x, point.y)`, `select_all_extract()`. Return extracted text.
  - `"prompt_user"`: `prompt_user_blocking(step["question_text"])`. Return response text.
  - `"wait"`: Create ConditionChecker from step["wait"], call poll_until(). Return condition result detail.
  - `"loop"`: handled separately in run_routine, raise ValueError if reached here.
  - Default: `click(point.x, point.y)`. Log warning.
- All executor calls pass `dry_run=dry_run`.

**`_compute_search_region(pos_pct: dict, screen_w: int, screen_h: int) -> tuple[int, int, int, int]`:**
- Center region on recorded position percentage
- Width = `int(screen_w * 0.35)`, Height = `int(screen_h * 0.35)` (slightly larger than 25% for overlap)
- Clamp to screen bounds
- Return `(rx, ry, rw, rh)`

**`_failure_cascade(step: dict, routine: Routine, routine_dir: Path, run_dir: Path, callback: RunCallback | None) -> LocateResult | None`:**

5-stage failure recovery:

Stage 1 -- Retry at position (2 attempts):
```python
for attempt in range(2):
    try:
        result = locate_element_from_step(step, routine_dir)
        if result is not None:
            return result
    except ElementNotFoundError:
        time.sleep(1.0)
```

Stage 2 -- 25% region scan:
- Compute search region via _compute_search_region
- Take screenshot_region of that area
- Run locate_element_from_step with the step but skip position fallback
- If found, adjust coordinates back to full-screen space

Stage 3 -- Full-screen cascade:
- Run locate_element_from_step with full parameters (no skip)
- If found, return result

Stage 4 -- LiteLLM AI fallback:
- Take full screenshot, base64 encode it
- Build smart prompt using `_build_ai_fallback_prompt(routine, step_index, step, screenshot_b64)`
- Send to LiteLLM via `litellm.completion()` with the configured model
- Parse JSON response for x, y, confidence
- If confidence >= 0.5, return LocateResult
- Save annotated screenshot to run_dir

Stage 5 -- Abort:
- Save annotated failure screenshot with all detected bboxes drawn
- Return None (caller will abort)

At each stage, emit `RunEvent.STEP_RETRY` via callback.

**`_build_ai_fallback_prompt(routine: Routine, step_index: int, step: dict, screenshot_b64: str) -> str`:**
- Build the prompt from RESEARCH.md pattern (routine context, step list with progress markers, current step details, instructions)

**`run_routine(routine_dir: Path, *, callback: RunCallback | None = None, dry_run: bool = False) -> RunResult`:**

Main entry point:

1. Load routine: `routine = Routine.load(routine_dir)`
2. Pre-flight: `errors = preflight_check(routine, routine_dir)`. If errors, emit PREFLIGHT_FAILED, return failed RunResult.
3. Emit PREFLIGHT_OK
4. Create run dir: `run_dir = create_run_dir(routine_dir)`
5. Set up file logger: `handler = setup_run_logger(run_dir)`, add to root logger
6. Desktop setup: if `routine.start_from == "desktop"` and config `replay.auto_minimize` is True:
   - On Windows: `import subprocess; subprocess.run(["powershell", "-c", "(New-Object -ComObject Shell.Application).MinimizeAll()"], ...)` or use existing `platform_utils.minimize_all_windows()`
   - Sleep 1s for windows to minimize
7. Emit RUN_START with routine name, step count
8. Step loop:
```python
step_results = []
steps_completed = 0
for i, step in enumerate(routine.steps):
    action = step.get("action", "click")

    # Handle loop steps inline
    if action == "loop":
        _handle_loop_step(step, routine, routine_dir, run_dir, i, callback, dry_run, step_results)
        steps_completed += 1
        continue

    emit(STEP_START, {step_index, total_steps, label, action})

    # Locate element (skip for wait, prompt_user -- they don't need location)
    if action in ("wait", "prompt_user"):
        locate_result = LocateResult(point=Point(0, 0), confidence=1.0, method="none")
    else:
        try:
            locate_result = locate_element_from_step(step, routine_dir)
            emit(ELEMENT_LOCATED, {point, method, confidence})
        except ElementNotFoundError:
            # Enter failure cascade
            locate_result = _failure_cascade(step, routine, routine_dir, run_dir, callback)
            if locate_result is None:
                # ABORT -- never blind-click
                emit(STEP_FAILED, ...)
                failure_reason = f"Could not find element '{step.get('label', '?')}' after full cascade"
                break

    # Screenshot before action
    before_img = screenshot_full() if action not in ("wait", "prompt_user") else None
    if before_img is not None and callback:
        callback(RunEvent.SCREENSHOT_TAKEN, {"purpose": "before_action", "step_index": i})

    # Execute action
    action_result = _dispatch_action(step, locate_result, dry_run=dry_run)
    emit(ACTION_EXECUTED, ...)

    # Post-action validation (skip for wait, prompt_user, read, snip_and_search, select_all_extract)
    if action not in ("wait", "prompt_user", "read", "snip_and_search", "select_all_extract") and before_img is not None:
        after_img = screenshot_full()
        if callback:
            callback(RunEvent.SCREENSHOT_TAKEN, {"purpose": "after_action", "step_index": i})
        validation = validate_action(before_img, after_img, f"{action} on '{step.get('label', '')}'")
        if not validation.success:
            emit(VALIDATION_FAILED, ...)
            # Log but continue -- don't abort on validation failure alone
        else:
            emit(VALIDATION_PASSED, ...)

    emit(STEP_COMPLETE, ...)
    steps_completed += 1
    step_results.append({...})
```
9. Save run result, remove file logger, prune old runs
10. Return RunResult

**`_handle_loop_step(step, routine, routine_dir, run_dir, step_index, callback, dry_run, step_results)`:**
- Get loop definition from `step["loop"]`
- Get `body_step_node_ids` from loop def
- Find body steps by matching node_id in routine.steps
- Create ConditionChecker from loop exit condition
- Loop: execute body steps in order, then check condition via poll_until (single poll, not blocking)
- Use `max_iterations` from loop def as safety limit
- Emit LOOP_ITERATION events

**IMPORTANT: SCREENSHOT_TAKEN event.** Every call to `screenshot_full()` during the step loop MUST be followed by emitting `RunEvent.SCREENSHOT_TAKEN` via the callback (if callback is provided). This event is consumed by the ReplayOverlayAdapter (Plan 04) to trigger the camera flash effect. The data dict should include `{"purpose": "before_action"|"after_action"|"failure_log", "step_index": i}`.
