**api/run_manager.py** -- Create thread-safe RunManager class:

```python
from __future__ import annotations
import threading
import uuid
import logging
from dataclasses import dataclass, field
from enum import Enum
from typing import Any

class RunStatus(str, Enum):
    RUNNING = "running"
    WAITING = "waiting"
    PAUSED = "paused"
    COMPLETED = "completed"
    FAILED = "failed"

@dataclass
class ActiveRun:
    run_id: str
    routine_id: str
    status: RunStatus = RunStatus.RUNNING
    current_step: int = 0
    total_steps: int = 0
    error: str | None = None
    prompt_text: str | None = None
    abort_event: threading.Event = field(default_factory=threading.Event)
    thread: threading.Thread | None = None
```

RunManager class with:
- `__init__`: `self._lock = threading.Lock()`, `self._active: ActiveRun | None = None`, `self._history: dict[str, ActiveRun] = {}`
- `start_run(routine_id: str) -> str`: Under lock, check if `self._active` is in RUNNING/WAITING/PAUSED status. If so, raise `RunAlreadyActiveError`. Generate `run_id = uuid.uuid4().hex[:12]`. Create `ActiveRun(run_id=run_id, routine_id=routine_id)`. Set `self._active = run`. Return run_id
- `get_run(run_id: str) -> ActiveRun | None`: Under lock, check `self._active` then `self._history` by run_id
- `update_step(run_id: str, step_index: int, total_steps: int) -> None`: Under lock, if active matches run_id, update `current_step` and `total_steps`
- `mark_waiting(run_id: str, prompt_text: str) -> None`: Under lock, set status=WAITING, prompt_text
- `mark_paused(run_id: str) -> None`: Under lock, set status=PAUSED
- `mark_complete(run_id: str) -> None`: Under lock, set status=COMPLETED, move to `_history`
- `mark_failed(run_id: str, error: str) -> None`: Under lock, set status=FAILED, error, move to `_history`
- `_archive(run: ActiveRun) -> None`: Move from `_active` to `_history`, set `self._active = None`

Custom exceptions:
- `class RunAlreadyActiveError(Exception): pass`
- `class RunNotFoundError(Exception): pass`

**api/lifecycle.py** -- Daemon thread server:

```python
from __future__ import annotations
import logging
import threading
import uvicorn
from core.config import get_config

class _NoSignalServer(uvicorn.Server):
    def install_signal_handlers(self) -> None:
        pass  # Qt owns signals

def start_api_daemon(app: Any, host: str | None = None, port: int | None = None) -> threading.Thread:
    config = get_config()
    api_cfg = config.get("api", {})
    h = host or api_cfg.get("host", "127.0.0.1")
    p = port or api_cfg.get("port", 8420)
    uv_config = uvicorn.Config(app, host=h, port=p, log_level="info")
    server = _NoSignalServer(uv_config)
    thread = threading.Thread(target=server.run, daemon=True, name="ocsd-api")
    thread.start()
    return thread
```
